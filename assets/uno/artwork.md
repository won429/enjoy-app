# UNO game artwork

Created with the built-in ImageGen tool on 2026-10-11. All production artwork is original generated art. The supplied reference is used for perimeter seating, fan composition and casual mobile-game art direction. The user explicitly requested different card art; the initial oval/logo variants are not used by the application.

Production files: avatars.webp (1983×793), card-faces.webp (2048×768), card-back.webp (1024×1536), card-wild.webp (1024×1536), table.webp (1536×1024). WebP files retain the generated resolution and use quality90 encoding. PNG files preserve the originals.

Avatar prompt: Exact5×2 atlas of ten distinct friendly polished3D cartoon young-adult head/bust portraits; ten equal square tiles with no gutters, text or borders. Different hair, glasses and skin tones; vibrant pastel backgrounds. Centered faces safe within inner80%, original characters, no emoji.

Card face and wild prompts: see card-faces.prompt.txt and card-wild.prompt.txt.

Card back prompt: One original flat2:3 midnight-navy playing-card back, thin ivory rounded border, asymmetrical interlocking angular coral-red, sunny-yellow, emerald and cobalt ribbons, subtle dotted printed texture. Bold cream uppercase DROP centered. No UNO lettering, oval or swoosh, no extra words or emoji.

Table prompt: see table-prompt.md.

UI numbers are actual card values, with Korean accessible labels. Special actions and trophies use the app's existing Phosphor icon font, not emoji. No card logic, Firebase paths, transactions or engine rules were changed for the artwork.
